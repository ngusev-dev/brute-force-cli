# Перебор пароля по хэшу

На входе — алгоритм и хэш. На выходе — найденный пароль, количество проверок, время и средняя скорость. Статистика выводится только после завершения поиска или остановки через Ctrl+C.

```powershell
npm ci
npm run build
npm start -- md5 a1d0c6e83f027327d8461063f4ac58a6
```

Пример находит пароль `42`. Поддерживаются `md5`, `sha1`, `bcrypt`, `argon2`.

Хэши bcrypt и Argon2 в PowerShell заключайте в одинарные кавычки:

```powershell
npm start -- bcrypt '$2a$10$z4u9ZkvopUiiytaNX7wfGedy9Lu2ywUxwYpbsAR5YBrAuUs3YGXdi'
```

Программа использует `worker_threads` и автоматически выбирает число потоков по доступным логическим процессорам. Для Argon2 учитывается размер общего пула libuv (по умолчанию 4), который использует нативная библиотека. Дополнительные аргументы не нужны.

Сначала проверяются пароли из `src/rockyou-75.txt` — один пароль на строку, кодировка UTF-8. Список распределяется между потоками. Если пароль найден в словаре, полный перебор не запускается. Если совпадений нет, все потоки завершают словарь и переходят к полному перебору.

Повторяющиеся и пустые строки словаря пропускаются. Пробелы в начале и конце строки сохраняются как часть пароля. Уже проверенные словарные пароли повторно при полном переборе не хэшируются. Если файла нет, программа сразу начинает полный перебор. Путь к словарю определяется относительно проекта и не зависит от текущей папки терминала.

При полном переборе сначала проверяется пустой пароль. Затем для **каждой длины** выполняются этапы:

1. Только цифры: `0`…`9`, для двух символов — `00`…`99`.
2. Только латинские буквы, строчные и заглавные.
3. Сочетания букв и цифр, содержащие и букву, и цифру.
4. Варианты со знаками и пробелом, включая их сочетания с буквами и цифрами.

После всех этапов длина увеличивается. Верхнего предела длины нет. Глобальный этап «все числовые пароли любой длины» был бы бесконечным и никогда не перешёл бы к буквам, поэтому этапы выполняются отдельно для каждой длины.

Внутри этапа каждый поток проверяет свою часть комбинаций. Все потоки заканчивают текущий этап до начала следующего. Уже проверенные варианты не хэшируются повторно. Используются 95 печатных ASCII-символов: латинские буквы, цифры, знаки и пробел.

После нахождения пароля все потоки останавливаются. **Ctrl+C** также останавливает весь поиск, включая проверку словаря. Уже начатые проверки завершаются, после чего выводится общая статистика: число потоков, сумма проверок, время и средняя скорость. Счётчик хранится как `bigint`; время включает чтение словаря, запуск и завершение потоков. Проверки словаря и полного перебора суммируются. Из-за параллельного порядка число проверок до нахождения пароля может отличаться между запусками. На очень коротком поиске запуск потоков может занимать больше времени, чем сам перебор.

Соль и параметры bcrypt/Argon2 берутся из хэша.

Полный перебор, особенно bcrypt/Argon2, может занимать очень долго. Программа ищет до нахождения пароля или остановки пользователем. Символы вне печатного ASCII в текущий алфавит не входят; сам алфавит задан в `src/search.ts`.

Код состоит из четырёх файлов:

- `src/cli.ts` — аргументы и вывод статистики.
- `src/search.ts` — чтение словаря, распределение кандидатов, запуск потоков и общая статистика.
- `src/worker.ts` — проверка кандидатов в отдельном потоке.
- `src/hashing.ts` — проверка MD5/SHA-1 через Node.js, bcrypt через bcryptjs и Argon2 через argon2.

Требуется Node.js 22+. Проверка: `npm test`.
