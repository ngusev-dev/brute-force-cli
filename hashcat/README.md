### Короткая команда для заданного диапазона

| Алгоритм | Режим `-m` |
| -------- | ---------: |
| MD5      |        `0` |
| SHA-1    |      `100` |
| bcrypt   |     `3200` |
| Argon2   |    `34000` |

```powershell
.\hashcat.exe -m 100 -a 3 '6e157c5da4410b7e9de85f5c93026b9176e69064' '?a?a?a?a?a?a' --increment --increment-min 1 --increment-max 6 --markov-disable --potfile-disable --restore-disable
```

`--potfile-disable` исключает сохранённые результаты из повторного замера; `--restore-disable` отключает запись файла восстановления. В отчёте укажите выбранный алфавит, диапазон длин и используемое CPU/GPU. Если пароль не найден за отведённое время, запишите «не найден за N с».
